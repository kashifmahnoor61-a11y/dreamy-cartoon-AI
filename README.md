# Dreamy Cartoon AI

Bilingual (Urdu, Roman Urdu, English) AI assistant starter.

## Deploy
1. Import this GitHub repository into Vercel.
2. In Vercel Project Settings → Environment Variables, add `OPENAI_API_KEY`.
3. Optionally add `OPENAI_MODEL` (default: `gpt-4.1-mini`).
4. Redeploy after adding variables.

Never put a real API key in `index.html`, commit it to GitHub, or share it in chat.

## Important
This starter needs an OpenAI API account. API usage may cost money; ChatGPT subscriptions and API billing are separate. Add usage limits and monitoring before making the site public. User accounts, subscriptions, payment processing, image generation and video generation are not included yet.
